# Student Study Hours Evaluator (React.js)

A modern, responsive single-page web application built with **React.js** to evaluate student performance based on daily study hours.

---

## ✨ Features

- **Single-Page Architecture**: Clean layout comprising a professional **Header**, a central **Evaluation Form**, and a comprehensive **Footer**.
- **Accurate Pass / Fail Prediction**:
  - **Passing Benchmark**: $\ge 4.0\text{ hours/day}$
  - **Pass State**: Celebratory emerald UI, confetti animation, and readiness percentage.
  - **Fail State**: Warning alert, preparedness score, and constructive recommendation.
- **Robust Validation**: Detects empty inputs, non-numeric entries, negative values, or values greater than 24 hours.
- **Interactive Quick-Presets**: 2.0 hrs, 4.0 hrs, and 6.5 hrs for instant testing.
- **100% English Content**: All labels, headings, prompts, messages, and notes are presented in professional English.
